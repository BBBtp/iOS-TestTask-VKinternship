В ветке **review-photo-async** реализована асинхронная загрузка фото отзывов, но при первом запуске немного лагает UI (картинки кешируются поэтому потом все становится окей). Проблема возможно в большом размере картинки или в количестве элементов в одном листе пагинации. В любом случае решил вынести это в отдельную ветку. При асинхронной загрузке аватаров такой проблемы нет.
